# Environmental Statistics
## Lecture 2: Count Data Analysis
This lecture introduces **regression models for count data**. Count responses are non-
negative integers, such as the number of birds observed, the number of trees dying, or the
number of events recorded during a survey.

The main idea is that the response does not always need to follow a *normal distribution*.
Instead, we can choose a probability distribution that is appropriate for the type of
response being analysed.

### Learning Objectives
By the end of this lecture, you should be able to:
-  Recognise when a response variable should be analysed as count data.
-  Understand why ordinary Gaussian regression is not appropriate for many count
responses.
-  Understand the role of a *link function* in count regression.
-  Explain why the expected count must remain *non-negative*.
-  Distinguish between the **Poisson** and **negative binomial** distributions.
-  Diagnose and account for *overdispersion*.
-  Understand why a simpler distribution should be preferred when a more complex
model is not supported by the data.
-  Understand why regression coefficients in count models are often difficult to interpret
directly.
-  Communicate model results using predictions and confidence intervals on the
response scale.
