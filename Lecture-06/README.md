# Environmental Statistics
## Lecture 6: Simulating Data and Model Diagnostics Using Simulation

A good statistical model should describe the observed data adequately while also satisfying the assumptions required by the model. This lecture introduces simulation-based diagnostics: instead of relying only on conventional residuals, we simulate data from the fitted model and compare the observed data with what the model predicts.

### Learning Objectives
By the end of this lecture, you should be able to:
- Understand what makes a statistical model adequate: a good fit to the data and reasonable model assumptions.
- Recognise why graphical inspection of data and model fits is important, using the *Anscombe quartet* as an example.
- Distinguish between an outlier, a high-leverage observation, and an influential observation.
- Understand why conventional residuals can be difficult to interpret for Poisson and Bernoulli GLMs.
- Understand the basic principle of simulation-based model diagnostics.
- Simulate data from a fitted statistical model using estimated parameters and the assumed response distribution.
- Understand the role of random-generation functions such as `rnorm()`, `rpois()`, `rbinom()`, and `rnbinom()`.
- Understand why simulations are repeated many times when assessing model fit.
- Determine where an observed response lies within its simulated distribution using an empirical quantile.
- Understand the connection between simulated quantiles and the probability integral transform.
- Understand the basic idea of a parametric bootstrap and how it differs from simulation with fixed fitted parameters.
- Understand how residual diagnostics can reveal problems with both the functional form and the assumed response distribution of a model.
