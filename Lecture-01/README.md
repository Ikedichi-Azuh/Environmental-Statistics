# Environmental Statistics
## Lecture 1: Multivariate Regression
This lecture introduces regression analysis as a framework for understanding how a response variable can be explained by one or more predictors. The focus is on developing the statistical thinking needed to fit, interpret, and communicate regression models in environmental and scientific applications.

### Learning objectives
By the end of this lecture, you should be able to:
-  Understand the role of regression analysis in environmental statistics and scientific research.
-	 Distinguish between univariate regression, multiple regression, and regression models containing interactions.
-	 Interpret regression model parameters in the context of the variables being studied.
-	 Distinguish between the part of the response explained by the predictors and the unexplained residual variation.
-	 Understand why estimates should be accompanied by measures of uncertainty, such as 95% confidence intervals.
-	 Use model predictions and confidence intervals to communicate regression results graphically.
-	 Recognise the assumptions made about the model errors and understand why these assumptions matter.
-	 Understand the role of well-formulated hypotheses when interpreting p-values.
-	 Recognise the generalised linear model (GLM) framework as a general approach to parameter estimation for a range of statistical models.

### Statistical tools and workflow
Throughout this course, **R/Python** will be used for statistical analysis. **Quarto/Jupyter/VS Code** will be used to develop reproducible analyses and reports.
The emphasis is not only on obtaining statistical results, but also on producing analyses that are reproducible, interpretable, and suitable for scientific communication.
