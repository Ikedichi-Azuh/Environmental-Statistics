# Environmental Statistics
## Lecture 5: Recapitulation I 
Lecture 5 recapitulates the main ideas from Lectures 1–4. The aim is not to introduce a
new modelling framework, but to connect the concepts developed so far:
- what a GLM actually provides;
- how to interpret a fitted model;
- how ANOVA relates to the GLM;
- how different ways of handling predictors affect inference;
- and how link functions and omitted predictors should be understood.
