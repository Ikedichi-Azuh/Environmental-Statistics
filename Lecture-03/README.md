# Environmental Statistics
## Lecture 3: Bernoulli and Binomial Analysis (Logistic Regression)
This lecture introduces regression models for **binary and binomial responses**. The
focus is on the Bernoulli and binomial distributions and the use of logistic regression
to model probabilities.

As in Lecture 2, the response does not need to follow a normal distribution. Instead, we
choose a probability distribution appropriate for the response and use a *link function*
to connect the expected response to a linear predictor.

For binary responses, the expected value is a probability and therefore must lie between
0 and 1.

### Learning Objectives
By the end of this lecture, you should be able to:
- Recognise when a response should be modelled using a Bernoulli or binomial distribution.
- Understand why a link function is required for modelling probabilities.
- Understand the role of the logit link in logistic regression.
- Explain why predicted probabilities must remain between 0 and 1.
- Distinguish between Bernoulli and binomial responses.
- Understand the role of a dispersion diagnostic for binomial models.
- Understand why logistic regression coefficients are often difficult to interpret directly.
- Use plots of model predictions and confidence intervals to communicate logistic regression results.
- Understand the characteristic sigmoidal shape of logistic regression.
- Recognise how a quadratic predictor effect changes the shape of the fitted relationship.
- Understand why omitting predictors can change coefficient estimates in logistic regression
